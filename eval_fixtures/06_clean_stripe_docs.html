Payment Intents API

Use the Payment Intents resource to track a single payment from creation through settlement.

How does the intent lifecycle transition?

Each intent moves monotonically from requires_payment_method to processing and finally succeeded.

Why pass an Idempotency-Key header?

Clients send a UUID v4 in Idempotency-Key so safe network retries return the original server response without double-charging.
