Using the Fetch API Safely

The fetch() function returns a Promise that resolves to a Response once HTTP headers arrive from the server.

What triggers a CORS preflight OPTIONS request?

Requests using HTTP methods beyond GET, HEAD, or POST, or setting custom headers like Authorization, send an OPTIONS preflight request first.

How do I cancel an in-flight request with AbortController?

Pass signal: controller.signal into the fetch() options object and call controller.abort() when the timeout expires.
